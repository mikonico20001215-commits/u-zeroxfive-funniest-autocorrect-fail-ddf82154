One line for make.fun's "Funniest Autocorrect Fail" bounty: a text message where autocorrect turns a confession of love into a misunderstanding with the wrong person entirely. The joke lands in the gap between what was typed and what was sent — and in who ends up reading it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `out/entry.txt` locally, or to `/output/entry.txt` where the competition runs it. The line is a single line under 200 characters.
